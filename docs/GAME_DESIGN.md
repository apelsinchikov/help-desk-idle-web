# Game Design — Help Desk Idle

## Фантазия игрока
Начинаешь эникейщиком, который просит «выключить и включить». Заканчиваешь IT-империей, которая внедряет ИИ во всё и «нагрузочно тестирует» конкурентов. Юмор — узнаваемые IT-клише (см. `CONTENT.md`). Референс по структуре — AdVenture Capitalist.

## Core loop
1. **Тап по строке работы** (вся карточка — зона нажатия) → запуск цикла, полоска заполняется за `cycle` секунд.
2. Полоска заполнена → работа в состоянии **«Готово — собрать»** и стоит. Деньги ещё НЕ на счету.
3. **Тап по строке** → деньги зачисляются (`payout`), работа **встаёт** (idle). Новый цикл — только следующим тапом; сама работа никогда не стартует.
4. Деньги → покупка уровней работы (цена растёт экспоненциально).
5. Пороги уровней (25/50/100/…) → **достижения**: ускорение ×2 или прибыль ×N.
6. **Менеджер** работы → сам собирает и перезапускает цикл (в т.ч. оффлайн). Без менеджера работа после цикла ждёт игрока — поэтому менеджеры важны.
7. Достигнут нужный уровень предыдущей работы → можно купить (открыть) следующую.
8. Поздняя игра: **«Расформировать IT-отдел и собрать новый»** (престиж) → TechCoin → постоянный бонус к прибыли.

## Открытие работ
Работа N видна сразу, но заблокирована. На карточке: «Нужно: *<Работа N−1>* ур. 25 · Открыть за $X».
- Условие: `level(N−1) ≥ unlockLevel` (по умолчанию 25, в JSON). Открытие = покупка 1-го уровня по `baseCost`.
- Работа 1 открыта с уровнем 1 бесплатно.

## Состояния карточки работы
`locked` (условие не выполнено) → `unlockable` (условие выполнено, можно купить) → `idle` (ждёт тапа) → тап → `running` (полоска идёт) → `ready` («Готово — собрать», подсветка/пульс) → тап (сбор) → `idle` → тап → `running`…
С менеджером: менеджер сам стартует и сам собирает: `running` → авто-сбор → `running`. Уровни работы покупает только игрок. При `cycle < 0.1 с` — полоска залита постоянно, показываем «$X / сек».

## Экраны и меню
**Главный экран:** шапка (аватар управляющего, баланс, доход/сек, 🍪, переключатель покупки ×1/×10/×100/Max), полоса **3 заданий** со звёздами (`PROGRESSION.md`), список работ, нижняя панель (Меню · Магазин). Боковых кнопок как в AdCap пока нет.
**Меню (лист снизу)** — пункты появляются по мере прогресса (`featureUnlocks` в JSON):
| Раздел | Вкладки | Что там | Когда открывается |
|---|---|---|---|
| Менеджеры | За деньги / За TechCoin | наём (автоматизация); за TechCoin — скидки на уровни, бонусы трудным работам | деньги ≥ цены первого менеджера |
| Достижения | Достижения / Галерея | ближайшая цель каждой работы и её награда; галерея — все пороги, будущие скрыты замком | первое достижение |
| Улучшения | За деньги / За TechCoin | разовые покупки: прибыль работы ×3, вся прибыль ×3; за TechCoin — сильнее | lifetime ≥ цены первого улучшения |
| Реорганизация | — | TechCoin на счету, бонус за монету, сколько получишь за сброс, кнопка сброса | можно получить ≥ 1 TechCoin |
| Гардероб | — | аватар и 7 слотов вещей | первая вещь |
| Задания | — | трек звёзд и награды | всегда |
| Магазин | — | сундуки, 🍪 | этап 4 |
| Настройки | — | язык RU/EN, звук/вибро, облако, сброс прогресса | всегда |

**Подсказки первого входа:** при первом открытии раздела — персонаж (Людмила Петровна / Тимлид) объясняет, что это. Показ один раз, флаг в сейве.
**Экран загрузки:** логотип, персонаж, полоска загрузки, шуточные статусы («Ищем кнопку "Пуск"…»).
**«С возвращением»:** сколько не было, сколько заработано оффлайн, кнопка «Забрать» (в будущем «Забрать ×2» за рекламу).

## Карточка работы (этап 2a)
Иконка — единственная зона тапа: старт / сбор (в «Готово» пульсирует с пометкой «Собрать»). Вся правая панель — покупка уровней
в текущем режиме; на пороге — кнопка повышения («Выпросить прибавку», «Пройти собеседование», …) с ценой и наградой.

## Обучение (этап 2a)
Шаги на главном экране по одному, по событиям игры, с затемнением и блокировкой всего, кроме подсвеченного: тап по иконке → сбор →
покупка уровня → режим покупки → открыть работу 2 → повышение → «Меню» → «Менеджеры» → «Нанять» → итог. Проходится один раз
(флаг в сейве, едет в облако). Новый раздел меню — своя подсказка Людмилы Петровны при первом входе.

## Анимация и фидбэк
- Полоска: плавное заполнение, вычисляется от `startedAt` (`TimelineView(.animation)`).
- `ready`: пульсация карточки; при сборе — всплывающее «+$X», хаптик, «тик» баланса.
- Достижение: вспышка карточки + тост с шуткой.

## Темы
Сейчас одна тема — **A «Офис и стикеры»** (светлая). Все цвета только через токены темы (`Theme`), никаких цветов в вью напрямую — тёмная тема C «Ночная смена» добавляется позже заменой токенов.

## Этапы
1. **Ядро:** 12 работ, тап-старт/тап-сбор, покупка ×1/×10/×100/Max, достижения (порог → эффект), менеджеры за деньги, оффлайн-доход + «С возвращением», экран загрузки, сохранение (локально + Supabase), RU/EN, тема A.
2. **Мета:** улучшения за деньги, галерея достижений, подсказки первого входа, открытие разделов меню по прогрессу, задания + звёзды + временные перки.
3. **Престиж:** Реорганизация, TechCoin и грейды, улучшения и менеджеры за TechCoin, гардероб.
4. **Монетизация:** печеньки 🍪, сундуки, реклама (×2, переработки), затем тема C, ивенты, Game Center.
Делаем строго по этапам; следующий — только после явного «го» автора.
