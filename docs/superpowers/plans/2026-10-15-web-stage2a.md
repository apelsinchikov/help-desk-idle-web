> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Tech Stack:** как в этапе 1 (Vite, TS, Preact + signals, `node --test`, Node 22).

### Task 5: Разделы и обучение (ядро)

**Files:** Create `web/src/core/progress.ts`, `web/src/core/progress.test.ts`

**Interfaces — Produces:**
- `type Section = 'managers' | 'achievements' | 'upgrades' | 'settings'`
- `refreshSections(engine): Section[]` — возвращает новые открытые и дописывает их в `state.ui.sections` (правила спеки §6)
- `type TutorialTarget = { kind: 'job-icon' | 'job-panel' | 'job-unlock'; jobId: string } | { kind: 'buy-mode' | 'menu' | 'menu-managers' | 'manager-hire' | 'none' }`
- `type TutorialView = { step: number; textKey: string; target: TutorialTarget; needsAck: boolean }`
- `tutorialView(engine, route: string): TutorialView | null` — null, если `tutorialDone` или текущий шаг ещё не должен показываться
- `tutorialAdvance(engine): void` — пропускает все шаги, чьё условие завершения уже выполнено; после последнего → `tutorialDone = true`
- `tutorialAck(engine): void` — завершает шаг с `needsAck`
- Шаги (индексы 0…9): 0 тап иконки (готово: `lifetimeEarnings > 0 || reboot.startedAt !== null`); 1 сбор (показ: reboot `ready`; готово: `lifetimeEarnings > 0`); 2 покупка (показ: можно купить reboot; готово: `reboot.level ≥ 2`); 3 режим покупки (показ: `reboot.level ≥ 4`; ack); 4 открыть работу 2 (показ: `canUnlock('plug_mouse')`; готово: её уровень ≥ 1); 5 повышение (показ: любая работа `atCap`; готово: любой `rank > 0`); 6 «Нажми Меню» (показ: любая `canHireManager`; готово: route ≠ 'jobs'); 7 «Менеджеры» (готово: route = 'managers'); 8 «Нанять» (готово: любой `hasManager`); 9 итог (ack) → done.
- Тексты: `tutorial.0…9` в `.xcstrings` (из спеки §7), `hint.managers|achievements|upgrades` (из `CONTENT.md`), `hint.speaker` («Людмила Петровна»), `common.gotIt` («Понятно»).
