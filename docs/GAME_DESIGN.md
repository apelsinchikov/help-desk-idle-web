# Game Design — Help Desk Idle

## Фантазия игрока
Начинаешь эникейщиком, который просит «выключить и включить». Заканчиваешь IT-империей, которая внедряет ИИ во всё и «нагрузочно тестирует» конкурентов. Юмор — узнаваемые IT-клише (см. `CONTENT.md`).

## Core loop
1. Тап по работе → полоска прогресса заполняется за `time` секунд.
2. Полоска заполнена → игрок получает `revenue × level × multipliers`.
3. Деньги → покупка уровней работы (цена растёт экспоненциально).
4. Уровень 25/50/100/… → milestone: работа выполняется в 2× быстрее.
5. Деньги → менеджер → работа перезапускается автоматически (и приносит доход оффлайн).
6. Достигнут нужный уровень предыдущей работы → можно купить (открыть) следующую.

## Правило открытия работ (отличие от AdCap)
Работа N видна сразу, но заблокирована. На закрытой карточке написано:
«Нужно: *<Работа N−1>* ур. 25 · Открыть за 💰 X».
- Условие: `level(N−1) ≥ unlockLevel` (по умолчанию 25, задаётся в JSON).
- Открытие = покупка 1-го уровня по цене `baseCost` работы N.
- Работа 1 открыта с уровнем 1 бесплатно.

## Экраны MVP
1. **Главный (список работ)** — шапка: баланс, доход/сек, переключатель покупки ×1 / ×10 / ×100 / Max. Вертикальный список карточек.
   - Карточка открытой работы: иконка (тап = старт), название, уровень + прогресс до следующего milestone, полоска выполнения с суммой за цикл и оставшимся временем, кнопка «Купить ×N — цена».
   - Закрытая карточка: силуэт иконки, условие и цена открытия.
   - Когда цикл < 0.1 с: полоска залита постоянно + «X / сек».
2. **Менеджеры** — список, цена, кнопка «Нанять».
3. **Настройки** — язык (RU/EN), звук/вибрация, облачное сохранение (статус, «Синхронизировать»), сброс прогресса.
4. **Окно «Пока вас не было»** — оффлайн-доход при возврате.

Навигация: нижний таб-бар (Работы / Менеджеры / Настройки).

## Анимация и фидбэк
- Полоска: плавное заполнение (вычисляется от `startedAt`, рисуется через `TimelineView(.animation)`).
- В момент выплаты: всплывающее «+X» над карточкой, лёгкий хаптик (только при ручном тапе), «тик» счётчика баланса.
- Milestone: вспышка карточки + тост с шуткой из `CONTENT.md`.

## Скоуп
**MVP (делаем):** 12 работ, тап-запуск, покупка ×1/×10/×100/Max, milestones (ускорение), 12 менеджеров, оффлайн-доход, автосохранение локально + Supabase-бэкап, RU/EN с переключением, иконки Fluent Emoji 3D.

**v2 (не делать без запроса):** престиж («Репутация»), апгрейды-мультипликаторы за деньги, глобальные milestones (все работы ≥ N), ивенты/миры (напр. «Бухгалтерия Edition»), монетизация (реклама ×2, IAP), достижения, Game Center, звук/музыка, античит оффлайна по серверному времени.
