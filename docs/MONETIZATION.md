# Монетизация (v2 — пока только заметки)

## Идеи (по мотивам AdCap)
- Rewarded-реклама: «×2 доход на 4 часа», «удвоить оффлайн-доход».
- IAP: стартовые паки, перманентный ×2, «Кофе для команды» (временный буст).
- Без принудительной межстраничной рекламы.

## Можно ли тестировать до релиза — да
- **Реклама (AdMob и др.):** тестовые ad unit ID и тестовые устройства работают в симуляторе и на iPhone без публикации. Реальные показы и выплаты — после выхода в App Store и привязки приложения к аккаунту.
- **Покупки (StoreKit 2):** `StoreKit Configuration File` в Xcode — локальные покупки в симуляторе/на устройстве без App Store Connect. Дальше — Sandbox-тестеры и TestFlight.
- Нужен платный Apple Developer Program ($99/год) для TestFlight, Sandbox и релиза.

## Архитектурный задел уже в MVP
- Мультипликаторы дохода — общий механизм `multipliers` (см. ECONOMY), временные бусты лягут туда же.
- Сохранение хранит `schemaVersion` — добавление покупок не сломает сейвы.

## Покупка печенек и тестовый режим
- Экран «Не хватает печенек» открывается при нехватке (из сундука) и по ссылке «Печеньки — купить» в магазине. Пакеты: 100 / 550 (+10%) / 1 200 (+20%) / 6 500 (+30%).
- Весь доступ к покупкам — через протокол `PurchaseService`:
  - `DebugPurchaseService` — начисляет печеньки бесплатно, на экране плашка «ТЕСТОВЫЙ РЕЖИМ». Включается только в сборках с флагом `DEBUG_PURCHASES` (Debug и TestFlight-конфигурация).
  - `StoreKitPurchaseService` — StoreKit 2; локально тестируется через `StoreKit Configuration File` без App Store Connect, затем Sandbox и TestFlight.
- Релизная конфигурация собирается без `DEBUG_PURCHASES` — бесплатных кнопок физически нет в бинарнике.
