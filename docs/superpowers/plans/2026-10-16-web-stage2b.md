# Веб — этап 2b: план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** задания и звёзды, трек наград, рюкзак перков и перемотка, плашка эффектов, гардероб (28 вещей, 7 слотов), магазин с описаниями сундуков, заявки в техподдержку.

**Architecture:** логика — чистые модули в `web/src/core` (`modifiers`, `perks`, `items`, `rng`, `track`, `quests`) + `GameEngine`, который учитывает модификаторы в цикле, выплате и цене уровней и режет время по истечениям перков; состояние — сейв v3 (едет в облако как раньше); UI — Preact. Три захода, после каждого — push и проверка автора на `/dev/`.

**Tech Stack:** Vite, TS, Preact + signals, `node --test`, Node 22.

**Spec:** `docs/superpowers/specs/2026-10-16-web-stage2b-design.md`

## Global Constraints
- Числа — только JSON в `Packages/HelpDeskCore/Sources/HelpDeskCore/Resources/`; строки — только `t()` / `Localizable.xcstrings` (ru + en, формат файла не менять: `json.dumps(indent=2, ensure_ascii=False)` без перевода строки в конце); цвета — `var(--…)`; иконки — `iconUrl()`.
- `src/core/**` без DOM и npm-зависимостей, импорты с `.ts`; время — мс, длительности — с.
- Скидка на уровни `≤ 0,5`, на грейд `≤ 0,5`; скидка не действует на повышение на пороге.
- Сообщения: 20 с, заявка раз в 180 с; плашка эффектов закрывается сама через 20 с.
- Сейв `schemaVersion = 3`, v2 мигрирует; v1 → v2 → v3 цепочкой.
- Git: ветка `dev`, Conventional Commits, автор `Evgeniy <evgenyassylov@gmail.com>`, **без трейлеров и упоминаний ассистента** (CLAUDE.md).
- Тесты: `cd web && node --test "src/**/*.test.ts"`; типы: `node_modules/.bin/tsc --noEmit -p .`. Сборка vite — только у автора/в CI.

## Review Focus
1. Перк истёк, пока игрок был вне игры, посреди цикла: доход с бонусом — только до истечения — тест в Task 4.
2. Надели/сняли вещь на скорость или включили перк посреди цикла: доля цикла сохраняется, цикл не завершается мгновенно и не сбрасывается — тест в Task 4.

4. Max-покупка со скидкой 50%: списывает ровно показанную цену и не превышает потолок — тест в Task 4.

### Task 4: Движок — бонусы, перки, перемотка

**Files:** Modify `web/src/core/engine.ts`; Create `web/src/core/perks.ts`, `web/src/core/perks.test.ts`, `web/src/core/rewind.test.ts`; Modify `web/src/core/engine.test.ts`

**Interfaces:**
- Consumes: `statTotals` (Task 3), `GameState.perks` (Task 2)
- Produces (engine): `cycle(jobId, at = now)` = прежний цикл / `(1 + speed)`; `payout(jobId, at = now)` × `(1 + salary)`; `quote`/`buy` — цена уровней × `(1 − levelDiscount)`, Max считает `maxAffordable(…, money / (1 − d))`; `activatePerk(perkId): boolean` (из рюкзака: −1 шт.; `rewind` → `rewind(minutes)`; остальное → `active.push({ id, until: now + minutes·60000 })`); `rewind(minutes): number` (заработано); `rewindPreview(minutes): number` (то же на копии `structuredClone(state)`, без изменений); `equip`/`unequip` появятся в Task 7 и обязаны идти через `changeModifiers`.
- Produces (perks.ts): `grantPerk(state, perkId, count = 1)`, `inventoryCount(state): number`, `activeEffects(content, state, at): { perk: PerkDefinition; remaining: number }[]` (по возрастанию `remaining`)
- Счётчики: `tap` на `ready` → `stats.collects++`; `hireManager` → `stats.hires++`; `buyUpgrade` → `stats.upgrades++`; `credit` → `stats.earned += amount`.

Алгоритм (не определяется сигнатурами):
```
changeModifiers(fn): для каждой открытой работы с startedAt запомнить cycleBefore; fn(); для идущих
  (managed: доля = ((at - startedAt)/1000 % cycleBefore)/cycleBefore; без менеджера: доля = min(1, (at - startedAt)/1000/cycleBefore))
  startedAt = at - доля · cycleAfter · 1000
advance(now, cap?): t = max(lastActiveAt, now - cap); пока есть active.until ∈ (t, now]: advanceTo(until), затем changeModifiers(удалить истёкшие);
  advanceTo(now); удалить истёкшие (until ≤ now)
rewind(T): для managed && !atCap: startedAt -= T·60000, затем сбор циклов как в advance до now при текущих модификаторах
  (таймеры перков не трогаются, оффлайн-лимит не применяется); без менеджера и startedAt != null: startedAt = min(startedAt, now - cycle·1000)
```
