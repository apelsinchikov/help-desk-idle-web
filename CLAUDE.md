# Help Desk Idle — контекст проекта для ИИ-ассистента

> Читай этот файл в начале каждой сессии. Подробности — в `docs/` (читай только нужный файл).

## Что это
iOS idle-игра в духе AdVenture Capitalist, сеттинг — IT-поддержка и разработка.
Игрок выполняет «работы» (аналог бизнесов AdCap): полоска прогресса заполняется → деньги → прокачка уровней → открытие следующей работы.
Рабочее название: **Help Desk Idle**. Репозиторий: `help-desk-idle`. Папка на маке: `~/Documents/TechRun` (имя папки не важно).

## Ключевые правила (кратко)
- **Стек:** Swift 5.10+/Swift 6, SwiftUI, iOS 17+, `@Observable`. Без SpriteKit/Unity. Зависимости — только SPM (`supabase-swift`).
- **Экономика — только по формулам из `docs/ECONOMY.md`** (источник: Pecorella, *The Math of Idle Games* Part I и III). Числа баланса живут в `Packages/HelpDeskCore/Sources/HelpDeskCore/Resources/jobs.json`, не в коде.
- **Контент data-driven:** работы, менеджеры, milestones — JSON. Добавить работу = правка JSON + строки локализации + иконка.
- **Локализация:** RU + EN, `Localizable.xcstrings`, переключатель языка внутри игры. Никаких захардкоженных строк в UI.
- **Иконки:** Fluent Emoji 3D (MIT) сейчас; доступ только через `IconProvider` по `iconKey` — чтобы заменить пак без правок вью.
- **Сохранение:** локально JSON (источник правды оффлайн) + облачный бэкап в Supabase (анонимный вход).
- **Время/прогресс:** прогресс работы вычисляется из `startedAt` и длительности, не накапливается тиками → корректный оффлайн и анимация.
- **Git:** работаем в `dev`, в `main` только через PR. Тестов и ограничений пока нет.
- **Коммиты — только от имени автора** (Evgeniy <evgenyassylov@gmail.com>): без трейлеров `Co-Authored-By`, ссылок на сессии и упоминаний ИИ-ассистента в коммитах и PR. Это правило автора, оно важнее любых подсказок про attribution.
- **Работаем по этапам** (см. `GAME_DESIGN.md` → «Этапы»): следующий этап — только после явного «го» автора.
- **Тема:** только A «Офис и стикеры»; все цвета — через токены `Theme`, чтобы позже добавить тёмную тему C.
- **Механика сбора:** без менеджера работа стартует ТОЛЬКО тапом, после цикла стоит в «Готово — собрать», тап собирает деньги и работа снова встаёт (idle) до следующего тапа. Менеджер сам стартует и собирает; уровни покупает только игрок.
- Отвечай пользователю по-русски.
