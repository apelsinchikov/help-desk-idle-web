# Этап 1 «Ядро» — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Играбельная iOS-версия ядра: 12 работ, тап-старт/тап-сбор, покупка ×1/×10/×100/Max, достижения-пороги, менеджеры за деньги, оффлайн-доход с экраном «С возвращением», экран загрузки, сохранение (локально + Supabase), RU/EN с переключением, тема A.

**Architecture:** Вся логика — в локальном Swift-пакете `HelpDeskCore` (без UI, чистые функции + `GameEngine`), тестируется `swift test` на маке без симулятора. Приложение `HelpDeskIdle` (SwiftUI, iOS 17) — только экраны, тема, ассеты, сохранение и облако. Прогресс работы вычисляется из `startedAt`; один и тот же код «догоняет» время и онлайн, и оффлайн.

**Tech Stack:** Swift 5.10 language mode, SwiftUI, Observation (`@Observable`), XCTest, SPM, `supabase-swift` 2.x.

**Spec:** `CLAUDE.md`, `docs/GAME_DESIGN.md` (раздел «Этапы», п.1), `docs/ECONOMY.md`, `docs/CONTENT.md`, `docs/ARCHITECTURE.md`; макеты — артефакт «Help Desk Idle — главный экран» (экраны «Главный экран», «Загрузка», «С возвращением», «Меню», «Менеджеры»).

## Global Constraints
- iOS 17.0+, SwiftUI, `@Observable`; без SpriteKit/Unity; единственная внешняя зависимость — `supabase-swift`.
- Формулы — только из `docs/ECONOMY.md`; числа баланса — только в JSON (`jobs.json`, `milestones.json`, `config.json`).
- Никаких строк UI в коде без локализации; языки `ru` (базовый) и `en`, переключатель внутри игры.
- Цвета — только через токены `Theme` (тема A); иконки — только через `IconProvider.image(for:)`.
- Без менеджера работа после цикла ждёт тапа; деньги зачисляются только при сборе.
- Коммиты в `dev`, автор `Evgeniy <evgenyassylov@gmail.com>`, без `Co-Authored-By` и упоминаний ассистента.
- Вне этапа 1 (не делать): задания/звёзды/перки, улучшения, галерея, TechCoin/реорганизация, гардероб, магазин/печеньки, реклама. В меню они показываются под замком «Скоро».

## Review Focus
1. Игра закрыта на дни → оффлайн ограничен `offlineCapHours` (24), без NaN/отрицательных, работы без менеджера стоят в «Готово». → тест в Task 5.
2. Часы устройства переведены назад (`now < lastActiveAt` или `< startedAt`) → прошедшее время = 0, деньги не теряются, прогресс не отрицательный. → тест в Task 4 и 5.
3. Денег чуть меньше цены / огромные числа → `maxAffordable` = 0, покупка не уводит баланс в минус (проверка `cost ≤ money` после расчёта). → тест в Task 2 и 4.
4. Очень быстрый цикл (< 1/30 с) у работы с менеджером → доход начисляется пачкой за тик, без цикла по каждому обороту. → тест в Task 4.
5. Повреждённый или неизвестной версии сейв → загрузка `save.prev.json`, иначе новая игра; приложение не падает. → тест в Task 6.

### Task 4: `GameEngine` — тап, сбор, покупки, менеджеры, догон времени

**Files:** Create: `Sources/HelpDeskCore/Engine/GameEngine.swift`; Test: `Tests/HelpDeskCoreTests/GameEngineTests.swift`

**Interfaces — Consumes:** Task 1–3. **Produces:**
- `@MainActor @Observable public final class GameEngine { private(set) var state: GameState; let content: GameContent; init(content: GameContent, state: GameState, now: @escaping () -> Date = Date.init)`
- `func status(of jobId: String) -> JobStatus`
- `func tap(jobId: String)` — `idle` → старт (`startedAt = now`); `ready` → зачислить `payout` в `money` и `lifetimeEarnings`, сразу старт нового цикла; в остальных состояниях — ничего.
- `func quote(jobId: String, mode: BuyMode) -> (count: Int, cost: Double)` — для `.max` через `maxAffordable`, для остальных фиксированное count (cost может быть > money).
- `@discardableResult func buy(jobId: String, mode: BuyMode) -> Bool` — только для открытых (level ≥ 1); false, если count == 0 или cost > money.
- `func canUnlock(jobId: String) -> Bool` / `@discardableResult func unlock(jobId: String) -> Bool` — условие: `level(prev) ≥ unlockLevel` и `money ≥ baseCost`; результат level 1.
- `@discardableResult func hireManager(jobId: String) -> Bool` — level ≥ 1, `money ≥ managerCost`, иначе false. После найма idle-работа стартует сама.
- `func advance(to now: Date, cap: TimeInterval? = nil) -> Double` — догоняет время, возвращает заработанное. Для работ с менеджером: `n = floor((now − startedAt)/cycle)`, `money += n·payout`, `startedAt += n·cycle` (при `cap` — сначала `startedAt = max(startedAt, now − cap)`). Если `cycle < fastCycleThreshold` — `status` = `.streaming(perSecond:)`. `now < startedAt` → считаем 0. Обновляет `lastActiveAt`.
- `var incomePerSecond: Double` — сумма `payout/cycle` по работам с менеджером.
