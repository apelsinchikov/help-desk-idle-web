# Экономика — Help Desk Idle

Источник формул: Anthony Pecorella, *The Math of Idle Games*
— Part I: https://www.gamedeveloper.com/design/the-math-of-idle-games-part-i
— Part III: https://www.gamedeveloper.com/design/the-math-of-idle-games-part-iii

Параметры работ — по образцу AdVenture Capitalist (из статьи и игры), расширены до 12 работ.
**Таблица — черновик**; финальный баланс подбираем симуляцией (`tools/sim`, позже).

## Обозначения
`b` — baseCost, `r` — growth rate, `k` — текущий уровень (owned), `n` — сколько покупаем, `c` — деньги игрока.

## Формулы (Part I)
- Цена следующего уровня: `cost_next = b · r^k`
- Цена покупки n уровней: `cost(n) = b · r^k · (r^n − 1) / (r − 1)`
- Максимум, который можно купить: `max = floor( log( c·(r−1) / (b·r^k) + 1 ) / log(r) )`
- Доход за цикл: `payout = revenue · k · M`, где `M` = произведение всех мультипликаторов
- Длительность цикла: `cycle = time / S`, где `S` = произведение ускорений от milestones
- Доход в секунду (для UI и оффлайна): `payout / cycle`

> Формулы bulk/max верны только для чистой экспоненты без сдвигов цены — у нас так и есть.

## Открытие работ
`unlockLevel = 25` у предыдущей работы (поле в JSON) + оплата 1-го уровня = `baseCost`.

## Milestones (на каждую работу, MVP)
Уровни 25, 50, 100, 200, 300, 400 → каждый делит `time` на 2 (S ×2, накопительно; на 400 = ×64).
Список уровней и эффектов — в JSON (`milestones`), чтобы позже добавить множители прибыли (как ×16 у AdCap на 500).

## Менеджеры
Одна разовая покупка на работу. Эффект: после выплаты цикл стартует сам; работа приносит доход оффлайн.

## Оффлайн-доход
`offline = Σ по работам с менеджером ( floor(elapsed / cycle) · payout )` + доведение текущего цикла.
`elapsed` ограничен `offlineCapHours` (конфиг, по умолчанию 24). Работы без менеджера: завершается максимум один текущий цикл.

## Быстрые циклы
Если `cycle < 1/30 с`: не анимируем каждый цикл; считаем количество завершённых циклов за кадр/тик и выплачиваем пачкой. UI показывает «X / сек».

## Престиж (v2, задел)
Формула AdCap (Part III): `angels = 150 · sqrt(lifetimeEarnings / 1e15)`; каждая единица «Репутации» = +2% к доходу.
Уже в MVP сохраняем `lifetimeEarnings`, чтобы v2 не ломала сохранения.

## Числа и формат
- Тип: `Double` (до ~1e308 хватит для MVP); при необходимости v2 — свой `BigNumber` (мантисса+экспонента).
- Формат: < 1 000 000 — с разделителями; далее `млн / млрд / трлн / квадрлн / квинтлн` (EN: million, billion, trillion, quadrillion, quintillion), затем `aa, ab, ac…`.
- Логика в `Core/Economy` — чистые функции без UI и сайд-эффектов.
